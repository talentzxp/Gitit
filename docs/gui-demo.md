# GitIt GUI demo

Generate an isolated synthetic folder for visual inspection:

    dotnet run --project src/GitIt.Benchmarks -- demo
    dotnet run --project src/GitIt.Desktop

Then choose **打开演示数据**. The generated folder contains a main version chain, two branches, exact duplicate copies, a copy/paste reconstruction expected to remain related-but-unproven or unlinked, and files with degraded provenance warnings.

This is strictly a GUI demonstration generated from \`GitIt.GroundTruth\`. It must never be used as real Word/WPS/WeChat corpus evidence.
